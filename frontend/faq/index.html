자주 묻는 질문

파일이 서버로 올라가나요?

아닙니다. HWPX를 여는 것도 미리보기를 만드는 것도 전부 브라우저 안에서 처리됩니다. 저장소나 데이터베이스를 쓰지 않습니다.

AI가 무엇을 바꿀 수 있나요?

문단과 표 안의 글자만 바꿉니다. 이미지, 표 구조, 도형, 페이지 설정은 건드리지 않습니다. AI에는 파일이 아니라 문단 텍스트만 전달되고, 실제 파일 수정은 브라우저 안에서 이뤄집니다.

AI가 엉뚱한 곳을 고치면요?

AI가 만든 수정 계획에는 "어느 문단의 어떤 원문을 무엇으로 바꿀지"가 들어 있습니다. 적용하기 전에 그 원문이 현재 문서와 정확히 일치하는지 확인하고, 한 건이라도 어긋나면 아무것도 바꾸지 않습니다. 일부만 반영되는 일은 없습니다. 수정한 내용은 화면에 바뀌기 전·후로 나란히 보여 주고, 확인한 뒤에 내려받으면 됩니다.

구형 .hwp도 되나요?

지원하지 않습니다. HWPX만 지원합니다. 한글에서 다른 이름으로 저장 → HWPX로 변환해 주세요.

미리보기가 한글에서 보던 것과 다릅니다

의도한 동작입니다. 미리보기는 내용 확인용이라 글꼴과 색, 정렬, 페이지 나눔을 재현하지 않습니다. 결과 파일을 한글에서 열면 원본 서식이 그대로 유지됩니다.

양식이 망가지지 않나요?

문서를 새로 그리지 않기 때문에 망가질 여지가 적습니다. 원본 파일에서 바뀌는 글자 구간만 교체하고 나머지 바이트는 그대로 둡니다. 다만 내용이 길어지면 표 높이나 페이지 나눔은 한글이 다시 계산합니다.

회사 문서를 올려도 되나요?

파일이 기기를 벗어나지 않으므로 기술적으로는 안전합니다. 다만 사내 규정은 조직마다 다르므로 민감한 문서는 담당 부서 정책을 먼저 확인해 주세요.

무료인가요?

네. 회원가입도 필요 없습니다.
