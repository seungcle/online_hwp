사용 가이드

지금은 HWPX를 열어 내용을 확인하는 단계까지 제공합니다.

1. 파일 열기

첫 화면의 상자에 .hwpx 파일을 끌어다 놓거나 클릭해서 선택합니다. 파일은 브라우저 안에서만 열리고 어디로도 전송되지 않습니다.

2. 미리보기 확인

문단과 표의 텍스트가 화면에 나옵니다. 글꼴과 색, 정렬, 페이지 나눔은 재현하지 않습니다. 한글과 똑같이 보이게 하는 것이 목적이 아니라 어디에 어떤 내용이 들어 있는지 빠르게 확인하는 것이 목적입니다. 실제 서식은 결과 파일을 한글에서 열었을 때 원본 그대로 유지됩니다.

3. 처리 시간 보기

주소 뒤에 ?debug=1을 붙이면 파일 읽기부터 화면 표시까지 각 단계에 걸린 시간이 표시됩니다.

구형 .hwp 파일이라면

rhwp는 .hwpx만 지원합니다. 구형 .hwp는 한글에서 파일 → 다른 이름으로 저장을 누르고 형식을 HWPX로 지정해 저장한 뒤 올려 주세요.

잘 처리되는 문서

  • 일반 문단으로 이루어진 공문, 보고서, 제안서
  • 표 안에 항목과 값이 들어간 양식
  • 이미지나 로고가 들어 있는 문서 — 이미지는 그대로 보존됩니다

아직 확인이 필요한 문서

  • 고정 크기 글상자에 긴 내용이 들어가는 양식
  • 머리말과 꼬리말, 각주, 메모 안의 텍스트
  • 차트나 수식이 본문 흐름에 섞여 있는 문서
